# Opencode Agent Documentation

This document describes the various sub-agents available in the opencode system and their purposes.

## Overview

Opencode uses specialized sub-agents to handle complex software engineering tasks. Each sub-agent has access to specific tools and is designed for particular workflows.

## Agent Types

### Core Agents

#### General Agent
**Description**: General-purpose agent for researching complex questions and executing multi-step tasks.

**Capabilities**:
- Executes bash commands
- Performs file operations (read, write, edit)
- Searches for files and content
- Reads and writes code

**Operations Documentation**:
- Execution log generation
- Error handling documentation
- Performance metrics collection
- Usage pattern reporting

**User Documentation**:
- Capability demonstration
- Request pattern examples
- Expected output formats
- Integration instructions with other agents

**Use Cases**:
- Task automation
- Complex command execution
- Parallel tool usage
- Multi-step software engineering tasks

#### Repository Agent
**Description**: Agent focused on understanding the repository structure and analyzing files.

**Capabilities**:
- Lists files and directories
- Searches for specific files using glob patterns
- Finds content within files
- Analyzes code in specific files

**Operations Documentation**:
- File search optimization metrics
- Pattern matching performance data
- Error handling for various file systems
- Large repository management documentation

**User Documentation**:
- Query syntax guide
- File pattern examples
- Regional language support
- Advanced search techniques

**Use Cases**:
- Repository exploration
- Analyzing file structures
- Understanding code organization
- Finding specific code entities

#### Documentation Agent
**Description**: Agent specialized for creating and managing documentation.

**Capabilities**:
- Reads documentation files
- Manages code-generation documentation
- Creates or updates README files
- Bulletproof content consistency checks

**Operations Documentation**:
- Documentation format standardization
- Content consistency validation rules
- Template management instructions
- Metadata extraction techniques

**User Documentation**:
- Documentation creation tutorials
- Content update examples
- Format validation explanation
- Troubleshooting incorrect formatting issues

**Use Cases**:
- Documentation creation
- Documentation updates
- Maintaining code generation records
- Creating project README files

## Examples of Agent Usage

### Creating a New Feature

1. **General Agent**: Analyzes the request and breaks it down into actionable tasks
2. **Repository Agent**: Explores the codebase to understand current structure
3. **General Agent**: Implements the new feature across multiple files
4. **Testing Agent** (if available): Runs tests to verify the implementation

### Generating Documentation

1. **Documentation Agent**: Creates structure for new feature documentation
2. **Repository Agent**: Identifies relevant code entities to document
3. **Documentation Agent**: Generates operations and user documentation
4. **General Agent**: Performs validation tests on generated content

## Multi-Agent Collaboration

The most powerful application of opencode is using multiple agents concurrently for optimal performance.

### Example: Complex Feature Implementation

1. Launch multiple agent instances in a single tool call
2. Assign different tasks to different agents
3. Agents work in parallel
4. Results are coordinated through the main agent
